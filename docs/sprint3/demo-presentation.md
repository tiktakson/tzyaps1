## Слайд 7. Якість і ризики (8:30–9:30)

**Release verdict:** поточний білд **не готовий** до релізу через `BUG-001` (P1).

**Залишкові ризики:**

1. Неможливість завершити бронювання через UI — критичний.
2. Некоректні дати бронювання — високий.
3. Недоступність контрола видалення з клавіатури — середній.
4. Некоректні контактні дані — середній.

**Що це означає:** функціональне покриття високе, але блокер не дозволяє підтвердити готовність продукту.
