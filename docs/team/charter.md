# **1.3 Домовленості команди (working agreement)**

* **Канал зв'язку**: [телеграм-чат](https://t.me/+Jb-Rbvcmk7Y1NTUy); час відповіді на повідомлення колеги — до 24 годин.  
* **Асинхронний standup**: кожен пише у чат у **пн до 17:00** два рядки — «що зроблено з моїх задач / що блокує». Скрам-майстер збирає блокери й виносить на обговорення.  
* **Строки внутрішньої здачі**: чернетки частин інкременту — за 3 дні до Demo; рецензування колегою — за 2 дні; зведення інкременту Керівником тестування — за 1 день.  
* **Правила комітів і гілок (зі спринта 4\)**: гілка на задачу за схемами feature/\<номер-задачі\>-\<коротка назва\> ; повідомлення коміту починається з ідентифікатора артефакту ( \[TC-07\] … , \[BUG-03\] … , \[US-05\] … ); злиття у main — через pull request після рецензії колеги; кожен комітить лише під власним GitHub логіном.  
* **Спільні документи:** одна папка команди [ТЗЯПЗ](https://drive.google.com/drive/folders/163cFUyJONmRP2w1tX-E1N3agNKb_FmFK?usp=drive_link); назви файлів — С\<номер спринта\>\_\<артефакт\> .  
* **Вирішення суперечок:** аргументоване обговорення до 30хв; за відсутності згоди — рішення Керівника тестування поточного спринта; суперечка щодо процесу — на найближчу ретроспективу; нерозв'язана — до викладача.
