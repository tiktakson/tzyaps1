# Інструкція з роботи з BPMN-моделями

## Інструмент та версія
Моделі розроблено з використанням інструменту **Draw.io** (версія 24.x) за допомогою інтегрованого плагіна **PlantUML**.

## Як відкрити файли
1. Відкрийте веб-версію [app.diagrams.net](https://app.diagrams.net/) або десктопний клієнт Draw.io.
2. Виберіть `File -> Open from -> Device...` і вкажіть `.drawio` файл (`01_booking.drawio` або `02_cancellation.drawio`).

## Як редагувати моделі
Оскільки моделі були частково згенеровані через PlantUML:
- Ви можете змінювати їх як звичайні фігури у Draw.io (перетягувати елементи, додавати нові зв'язки).
- Або ж ви можете відредагувати PlantUML-код: виділіть основний блок (UserObject), відкрийте вікно `Arrange -> Insert -> PlantUML` (або `Edit Data`), внесіть зміни у вихідний код PlantUML та натисніть "Apply". (Увага: це може перемалювати діаграму, тому після цього потрібно буде вирівняти пули та зв'язки вручну).

## Як оновити PNG
Після внесення змін у `.drawio` файл:
1. Виділіть усі елементи на полотні (`Ctrl+A` / `Cmd+A`).
2. Виберіть `File -> Export as -> Image (PNG)...`
3. У налаштуваннях експорту встановіть "Selection only" (якщо потрібно) та натисніть `Export`.
4. Збережіть файл поверх існуючого `.png` в цій директорії (`01_booking.png` або `02_cancellation.png`).
